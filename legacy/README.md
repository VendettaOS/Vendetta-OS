# Vendetta-OS
VendettaOS es una estación de trabajo experimental y persistente de DFIR basada en Arch Linux. Su propósito es organizar, verificar, procesar, analizar y preservar evidencia digital a lo largo de investigaciones de larga duración (Como para un caso o practicas a largo plazo)

## Estado del proyecto
Pues... esto es un legacy... así que esto no importa mucho, pero estaba pensando en hacer más herramientas y un "core"

# Objetivos iniciales
1. Gestión persistente de casos
2. Verificación de hash de evidencia 
3. Separación de evidencia original y copias de trabajo
4. Integración con herramientas DFIR establecidas
5. Almacenamiento y reapertura de casos a largo plazo

#### VendettaOS es un proyecto independiente de código abierto de hobby

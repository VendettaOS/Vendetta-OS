# Vendetta-OS
VendettaOS es una estación de trabajo experimental y persistente de DFIR basada en Arch Linux. Su propósito es organizar, verificar, procesar, analizar y preservar evidencia digital a lo largo de investigaciones de larga duración (Como para un caso o practicas a largo plazo)

## Estado del proyecto
Desarrollo del "Core" del OS (VCM)

# Objetivos iniciales
Gestión persistente de casos
Verificación de hash de evidencia [D]
Separación de evidencia original y copias de trabajo
Integración con herramientas DFIR establecidas
Almacenamiento y reapertura de casos a largo plazo
Configuraciones predeterminadas accesibles con personalización completa de Arch Linux

# VendettaOS

VendettaOS es un proyecto experimental orientado a la privacidad, la seguridad y el análisis forense digital

La idea es construir poco a poco una colección de herramientas modulares que puedan funcionar de manera independiente y, eventualmente, integrarse en un entorno común para administrar investigaciones y preservar su contexto a largo plazo

> VendettaOS se encuentra en una etapa temprana de desarrollo, eso quiere decir que no está preparado para investigaciones reales, uso pericial, entornos de producción ni manejo de evidencia sensible

## Sobre el proyecto

VendettaOS sigue siendo un proyecto personal y experimental mientras aprendo Python, Git y DFIR

El repositorio es público para documentar su progreso, todavía estoy entendiendo y reorganizando varias partes, así que probablemente cambie cosas a veces...

Algunas partes son prototipos, otras pueden cambiar completamente y otras todavía solo existen como ideas

## Filosofía

VendettaOS intenta seguir algunos principios:

- La evidencia debe conservar su contexto
- Los resultados derivados deben poder rastrearse hasta su origen
- Una herramienta debe poder funcionar sin depender de una GUI
- Los formatos deben ser sencillos, documentados y verificables
- La privacidad y la integridad deben considerarse desde el diseño

## Estructura del proyecto

La intención es que las herramientas puedan utilizarse de manera independiente desde la terminal y desde una futura interfaz unificada, si una herramienta no funciona o la GUI/CLI tiene un error tener una alternativa para poder seguir operando
